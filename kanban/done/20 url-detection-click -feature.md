# 20 url-detection-click -feature

## Summary

Terminal URLs are rendered as plain text with no visual distinction and no interaction.
Every modern terminal (iTerm2, Kitty, WezTerm) highlights URLs and opens them on
Ctrl+Click (macOS: Cmd+Click). This is a high-visibility QoL gap.

Flagged by **[Claude]** (QoL #7, worst feature #6).

---

## Implementation Plan

### Phase 1 — URL detection in the grid

- [x] After `grid_line` events are processed and the grid is updated, run a post-process
  pass over dirty lines to detect URL spans. Use a simple regex or state-machine scan:
  - Match `https?://[^\s]+` across consecutive cells in the same row.
  - Account for double-width cells (skip the continuation cell).
- [x] Store detected URL regions as a parallel `std::vector<UrlSpan>` per row, where
  each span has `{col_start, col_end, url_string}`.
- [x] Invalidate URL spans for a row whenever that row is marked dirty.

### Phase 2 — Visual underline for URL cells

- [x] When building the GPU cell array for rendering, check if a cell falls within a
  URL span. If so, set the URL-underline style bit in the cell's style flags.
- [x] Add a `STYLE_FLAG_URL` constant to `decoration_constants.h` (use `13 shader-constants-unification`).
- [x] Shader renders URL cells with a distinct underline (color or style distinct from
  Neovim's own underlines — e.g., dotted or colored).

### Phase 3 — Mouse hover and click

- [x] In the mouse-event handler (`SdlWindow` → `App` → `InputDispatcher` / host), on
  `SDL_EVENT_MOUSE_MOTION`, check if the cell under the cursor is part of a URL span.
  If so, set the OS cursor to a pointer (`SDL_SYSTEM_CURSOR_POINTER`).
- [x] On `SDL_EVENT_MOUSE_BUTTON_DOWN` with Ctrl (or Cmd on macOS) held, if the click
  lands on a URL span:
  - Extract the URL string.
  - Invoke the platform open command:
    - macOS: `open "<url>"`
    - Windows: `ShellExecuteW(NULL, L"open", url, ...)`
  - Do NOT forward the click to Neovim.
- [x] Without modifier held, let the click reach Neovim normally.

### Phase 4 — Config opt-out

- [x] Add `url_detection = true/false` to `config.toml` (default `true`).
- [x] When `false`, skip the detection pass entirely.

### Validate

- [x] Manually test: open a file with a URL, confirm underline, hover shows pointer cursor,
  Ctrl+Click opens the browser.
- [x] Run `py do.py smoke`.
- [x] Formatting is left to the repo pre-commit hook; do not run `clang-format` manually in this repo.

## Acceptance Criteria

- [x] HTTP/HTTPS URLs in grid cells are underlined with a distinct style.
- [x] Hovering over a URL cell changes the OS cursor to a pointer.
- [x] Ctrl+Click (Cmd+Click on macOS) opens the URL in the default browser.
- [x] Plain clicks without modifier are forwarded to Neovim normally.
- [x] `url_detection = false` in config disables the feature entirely.

## Completion Notes

Implemented with per-cell link IDs plus a link table in `Grid`; URL detection runs for dirty rows in `GridRenderingPipeline`, rendering marks hyperlinks with `STYLE_FLAG_HYPERLINK`, and `LocalTerminalHost` opens explicit OSC 8 links on plain click and detected URLs with Ctrl/Cmd-click. Coverage is automated via grid, terminal VT, terminal mouse, and config tests.
